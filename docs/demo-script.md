# AskBase: 60-second demo

## Prepare

Use a clean browser session and your own local database or isolated demo instance. Use the sample below instead of private documents. Confirm import, source details, and feedback work before recording. This is a recording plan, not evidence that a new demo has been recorded.

Turn the sample into a PDF named `community-workshop.pdf`:

## Recording sequence

| Time | Screen | Suggested narration |
| --- | --- | --- |
| 0–8 seconds | Open AskBase | “I built AskBase to ask questions about documents and check where the answers came from.” |
| 8–18 seconds | Upload the sample PDF and show the imported document | “It extracts the text, splits it into passages, and stores searchable embeddings in PostgreSQL.” |
| 18–33 seconds | Ask “What should I bring, and what does registration include?” | “The app retrieves relevant passages and streams an answer with numbered sources.” |
| 33–43 seconds | Open a source badge and compare it with the answer | “You can inspect the source instead of taking the answer on trust.” |
| 43–51 seconds | Submit feedback; show query history in your local admin view | “I added feedback and query monitoring to help investigate poor answers.” |
| 51–60 seconds | End on the app or architecture diagram | “The next step is evaluating retrieval with known answers, improving follow-up questions, and adding access controls for private use.” |
